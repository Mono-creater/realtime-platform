## 1. 系统架构与三种运行模式

### 1.1 数据流

```
 传感器(3×4-20mA)               汇川 H5U PLC                    平台 server.js
 ┌─────────────┐   GL10-4AD   ┌──────────────────────┐  Modbus TCP  ┌──────────────────┐
 │ 温度/压力/湿度│ ───────────► │ 100ms 采样             │  FC03 读      │ 解析主包/子包      │
 └─────────────┘              │ 10 条滑窗均值(1s)     │ ────────────► │ 异常→告警入库/广播  │
                              │ 阈值判异常             │               │ 双环 PID 控制引擎   │
                              │ 组主包(全部数据)       │  FC16 写      │ Z-N 阶跃整定       │
                              │ 组子包(异常数据)       │ ◄──────────── │ 接触力/姿态解算     │
                              │ 状态字/序号            │  30021/30022  │ → MonitorCar 页面  │
                              │ 读回写寄存器→比例阀/升弓│               └──────────────────┘
                              └──────────────────────┘
```

**关键设计**：均值、判阈、组包全部在 **PLC 侧**完成；平台只负责解析、显示、告警和控制。PLC 每 100ms 采样一次，每满 10 条（约 1s）更新一次均值寄存器。

### 1.2 三种运行模式

| 模式 | PLC_MODE | 数据来源 | 控制回路 | 用途 |
|---|---|---|---|---|
| **真实 PLC** | `real` + PLC_HOST 指向实体机 | PLC 主包/子包 | 真实闭环（FC16 写回） | 生产 |
| **模拟器闭环** | `real` + PLC_HOST=127.0.0.1:1502 | `plc-simulator.js` | 真实 Modbus 闭环 | 无 PLC 时的全链路测试（推荐） |
| **纯模拟** | `simulation` | 平台自生成随机数 | 内部植物模型 | 仅演示 UI/告警 |

> 模拟器在 **Modbus 协议层**忠实模拟 H5U：同样的寄存器、状态字、序号回绕、子包语义、写回寄存器，并带一阶滞后执行机构模型——平台无法区分它与真机。所有联调步骤都可先在模拟器上跑通。

## 2. H5U 硬件接线

### 2.1 传感器 → 模拟量模块

三路传感器均为 **4-20mA 电流输出**，接入 GL10-4AD（4 通道模拟量输入模块）：

| 传感器 | 量程 | 4mA | 20mA | 接 GL10-4AD 通道 |
|---|---|---|---|---|
| 温度变送器 | -10 ~ 80°C | -10°C | 80°C | CH0（VI0+ / VI0-） |
| 压力变送器 | 0 ~ 1000 kPa | 0 kPa | 1000 kPa | CH1（VI1+ / VI1-） |
| 湿度变送器 | 0 ~ 100 %RH | 0% | 100% | CH2（VI2+ / VI2-） |

接线注意：
- 模块需 24V DC 供电；传感器供电若为两线制，走模块的有源回路或外配 24V。
- 屏蔽线单端接地（建议 PLC 柜侧）。
- 下载程序前先用万用表串入回路确认 4mA 基流，避免接线短路。

### 2.2 量程换算

`H5U_main.st` 中按 `4mA=8000、20mA=40000`（GL10-4AD 默认原始值）换算，**若你的模块原始值范围不同，改程序里 `raw4mA`/`raw20mA` 两个常数**：

```
温度 = (raw - raw4mA) / (raw20mA - raw4mA) × 90 - 10    (°C)
压力 = (raw - raw4mA) / (raw20mA - raw4mA) × 1000       (kPa)
湿度 = (raw - raw4mA) / (raw20mA - raw4mA) × 100        (%)
```

## 3. AutoShop 配置与下载

### 3.1 网络设置

1. H5U 以太网口接网线，AutoShop 中设置 PLC IP（例：`192.168.1.88`，与上位机同网段）。
2. 上位机 ping 通后再进行 Modbus 配置。

### 3.2 使能 Modbus TCP 从站（MBS 服务）

1. AutoShop 打开 **MBS 从站配置**，启用从站，端口 **502**（Modbus TCP 标准端口），站号与平台 `.env` 的 `PLC_UNIT_ID` 一致（默认 1）。
2. 确认 **4x 保持寄存器 ↔ D 软元件的映射规则**（H5U 为直接对应：`4xN ↔ DN`）。
3. ⚠️ **地址为协议原值，不是 40001 偏移**。平台发出的 FC03 请求地址就是 30001 起；若 ModbusPoll 读 30001 是错的、读 30000 或 30002 是对的，说明你的工具加了 40001 偏移或映射差 1，按 [第 9 章](#9-故障排查表) 处理。

### 3.3 D 区容量限制（Easy 系列特别注意）

| 型号 | D 区范围 | 结论 |
|---|---|---|
| H5U 标准型 | D0 ~ D65535（或 ≥D32767） | 可直接用默认 30001-30022 段 |
| **H5U Easy（AutoShop）** | **D0 ~ D8191** | **D30001 不存在！** 用 D2001-2022 段 |

`plc-program/H5U_main.st` 默认按 **D2001-2022** 编写（Easy 安全），并同步改平台 `.env`：

```bash
PLC_REG_TEMP=2001  PLC_REG_PRESS=2002  PLC_REG_HUMID=2003
PLC_REG_STATUS=2004  PLC_REG_SEQ=2005
PLC_REG_SUB_BASE=2011  PLC_REG_WRITE_FORCE=2021  PLC_REG_WRITE_HEIGHT=2022
```

若为标准型 H5U 想用默认 30001 段：把程序里 D2001-2022 全局替换为 D30001-3022，`.env` 删掉上述 `PLC_REG_*` 行即可。

### 3.4 编译下载

1. 新建 ST 程序，把 `H5U_main.st` 内容粘贴（或导入），**替换 5 处占位软元件**：
   - `温度通道元件` `压力通道元件` `湿度通道元件` → 实际 AD 通道值寄存器
   - `比例阀输出元件` `升弓机构输出元件` → 实际 DA 输出寄存器
2. 确认 100ms 脉冲继电器（程序用 `SM4010`）与你的软元件手册一致，不一致则替换。
3. 编译 → 下载 → **重新上电**（掉电保持区见 5.4）。
4. 用 ModbusPoll 读 `4x2001~2005`（或 30001 段）核对数值与状态字。

## 4. Modbus 寄存器映射与报文协议

### 4.1 寄存器映射表（协议原地址；Easy 型用 2001 段，仅地址不同、语义相同）

| 地址(默认段) | Easy 段 | 含义 | 缩放 | 方向 |
|---|---|---|---|---|
| 30001 | 2001 | 温度 10 次均值 | ×10 有符号（负数补码） | R |
| 30002 | 2002 | 压力 10 次均值 | **×10**（0.1kPa） | R |
| 30003 | 2003 | 湿度 10 次均值 | ×10 | R |
| 30004 | 2004 | 状态字 | 见 4.2 | R |
| 30005 | 2005 | 主包序号 | 65535→1 回绕，0=旧固件 | R |
| 30011 | 2011 | 子包序号（=异常时主包序号） | — | R |
| 30012 | 2012 | 异常位图（bit0-2 同状态字） | — | R |
| 30013 | 2013 | 子包异常值·温度 | 同上 | R |
| 30014 | 2014 | 子包异常值·压力 | ×10 | R |
| 30015 | 2015 | 子包异常值·湿度 | ×10 | R |
| 30021 | 2021 | 接触力环输出=气囊压力设定 | **×10** kPa，钳位 50-1000 | **W (FC16)** |
| 30022 | 2022 | 姿态环输出=弓头高度设定 | mm，钳位 1000-2600 | **W (FC16)** |

> **为什么压力是 ×10 而不是 ×100？** 高压异常阈值 1000kPa，×100 后为 100000，**超出 uint16 上限 65535**，会导致 Modbus 从站报异常码 4（已在模拟器实测暴露）。×10 后 10000 安全落入 uint16，精度 0.1kPa（对接触力而言 0.1N 分辨率，足够）。若 PLC 程序与平台缩放不一致，数值会差 10 倍——见 [9.3](#9-故障排查表)。

### 4.2 状态字（30004）位定义

| 位 | 值 | 含义 |
|---|---|---|
| bit0 | 0x01 | 温度异常 |
| bit1 | 0x02 | 压力异常 |
| bit2 | 0x04 | 湿度异常 |
| bit6 | **0x40** | **扩展协议标志（新固件恒置）** |
| bit7 | 0x80 | 子包有效（本周期有异常） |

例：压力高压异常时状态字 = `0x40|0x80|0x02 = 0xC2`；温度高温异常 = `0xC1`。

### 4.3 子包语义

- **有异常**：主包照常携带全部均值数据，状态字置异常位 + bit7，同时子包（30011-30015）写入异常时的序号、位图和三个异常值。
- **无异常**：子包位图置 0，平台不读子包（状态字 bit7=0）。
- 平台发现异常后，按位图逐位生成与本地判阈同形的告警（类型/等级/数值），走统一告警入库与去重（同类型 10s 内且数值变化 <5% 不重复入库）。

### 4.4 新旧固件判定与回退

平台判定：`(状态字 & 0x40) != 0 或 序号 != 0` → 扩展协议，直接用 PLC 均值；否则视为**旧固件**（30004/30005 全 0），回退到平台侧 10 条缓冲均值 + 本地判阈的老路径（页面数据源标签显示"旧固件回退"）。

### 4.5 写回保活

自动调节或 Z-N 整定期间，平台**每 500ms 控制节拍**计算一次输出；输出值变化时立即 FC16 写 30021/30022，**输出不变时每 5s 保活重写一次**。原因：Z-N 整定阶跃期间输出恒定，保活写可防止 PLC 侧"写超时"看门狗或模拟器阀位漂移干扰整定。

## 5. PLC 程序说明

### 5.1 变量表（H5U_main.st）

| 变量 | 类型 | 说明 |
|---|---|---|
| `fifoT/fifoP/fifoH` | REAL[0..9] | 三路 10 深滑窗 FIFO |
| `sampleIdx` | INT | 当前滑窗位置（0-9） |
| `avgT/avgP/avgH` | REAL | 10 条均值 |
| `abnormal` | INT | 异常位图（0=正常） |
| `raw4mA/raw20mA` | REAL | AD 量程常数（按模块校准） |

### 5.2 执行流程（每 100ms 上升沿）

1. 三路 4-20mA → 工程量换算
2. 新样本覆盖 FIFO 最旧一条
3. 每满 10 条（1s）：求均值 → 判阈 → 主包写入 → 序号回绕 → 状态字/子包 → 读回写寄存器驱动比例阀/升弓机构

### 5.3 改阈值的位置

```pascal
IF avgT > 80.0 OR avgT < -10.0 THEN abnormal := abnormal OR 1;   END_IF;
IF avgP > 1000.0 OR avgP < 100.0 THEN abnormal := abnormal OR 2; END_IF;
IF avgH > 85.0 THEN abnormal := abnormal OR 4;                   END_IF;
```

改 PLC 程序后，**必须同步平台** `plc-packet.js` 的 `THRESHOLDS`（两处阈值保持一致，否则平台判定与 PLC 判定互相矛盾）。

### 5.4 掉电保持

序号、滑窗 FIFO 建议配掉电保持（D 区保持范围在 AutoShop 中设置）；若不掉电，重启后序号从 0 开始——平台会把 seq=0 误判为旧固件，直到第一次主包更新（最多 1s 影响，可接受）。

## 7. 无 PLC 模拟测试流程

> 全部步骤约 10 分钟，验证采集→异常→告警→闭环→整定全链路。

### 7.1 启动模拟器与平台

```bash
# 终端 1：模拟 H5U（默认 127.0.0.1:1502，站号 1）
npm run plc-sim

# 终端 2：平台（.env 用场景 B）
PLC_MODE=real PLC_HOST=127.0.0.1 PLC_PORT=1502 PLC_INTERVAL=1000 node server.js
```

观察模拟器日志：每 1s 一条 `[主包] seq=... 温度=25.0°C 压力=250kPa 湿度=45% 状态=0x40`。

### 7.2 页面验证

打开平台 → 环境参数页（MonitorCar）：
- 头部出现 **"PLC 实时数据"** 标签与 **seq=** 序号；三个传感器卡显示正常值（温度≈25、压力≈250、湿度≈45）。
- 受电弓卡显示弓头高度/接触力/θ1/θ2/气囊压力。
- 双环 PID 卡显示目标/测量/输出与 Kp/Ki/Kd。

### 7.3 异常注入验证

```bash
# Ctrl+C 停掉模拟器，带异常重新启动
npm run plc-sim:anomaly      # 等价 node plc-simulator.js --anomaly temperature:high
```

预期：温度卡**红色高亮** + "⚠️ 高温预警｜子包值 xx°C"徽标；头部出现闪烁的 **"⚠️ 子包异常 #seq"** 标签；告警列表新增"高温预警"记录（10s 去重窗口内不会重复刷）。其他注入：`--anomaly pressure:high`、`humidity:high`、`temperature:low`（可逗号组合）。

### 7.4 报文对照（curl）

```bash
curl http://localhost:3000/api/plc/packet
# 期望：main.status=0xC1(温度异常)，main.subValid=true，
#       sub.subSeq==main.seq，sub.values.temperature≈注入值
```

### 7.5 自动调节闭环

```bash
curl -X POST http://localhost:3000/api/control/auto \
  -H 'Content-Type: application/json' -d '{"loop":"force","enabled":true}'
```

观察模拟器日志出现 `◀ 收到 FC16 写: 30021 接触力环输出=...kPa`，`[执行机构] 压力设定=...` 逐渐逼近设定值；页面力环"测量"从 250N 收敛到目标 100N 附近（±5N）。姿态环同理 `{"loop":"posture","enabled":true}`，高度 1800→2400mm。

### 7.6 Z-N 阶跃整定

```bash
# 前提：力环已开启自动并收敛（整定必须从稳态开始！）
curl -X POST http://localhost:3000/api/control/tune \
  -H 'Content-Type: application/json' -d '{"loop":"force"}'
# 页面显示整定进度条；约 10-30s 后出结果：
#   ✅ K≈0.94 T≈1.9s L≈1.0s → Kp≈2.4 Ki≈1.2 Kd≈1.2
# 整定完成后自动恢复之前的自动状态，闭环用新增益继续收敛。
```

取消整定：`POST /api/control/tune/cancel`。一次只能整定一个回路；阶跃幅值 = 10% 量程（95kPa），**请勿在生产运行中整定**。

### 7.7 断开重连验证

Ctrl+C 停掉模拟器 → 平台日志出现 `❌ PLC 连接失败，2s 后重试`（退避 2s→4s→8s→…→30s 封顶）；重新启动模拟器 → 平台自动恢复采集。全程页面不崩溃。

### 7.8 纯模拟模式

`.env` 改 `PLC_MODE=simulation` 重启平台：页面数据源显示"模拟数据"，自动调节与 Z-N 整定照常可用（内部植物模型），适合无任何 PLC 环境的 UI 演示。

## 8. 真实 PLC 联调流程

> 按顺序执行，**每一步通过后再进下一步**。

1. **网络**：ping PLC IP；确认上位机防火墙放行 502。
2. **只读核对**：ModbusPoll 读 4x2001-2005（或 30001 段）：数值合理、状态字 bit6=0x40、序号每秒递增。平台先只连不写（不开自动），页面出现"PLC 实时数据"。
3. **人为触发子包**：把温度探头焐热/气吹过 80°C，观察状态字出现 0xC1、ModbusPoll 读 4x2011-2015 有值、平台红色卡片+子包徽标。
4. **静态标定（重要）**：
   - 升弓到几个已知压力点，测实际接触力，拟合 `F = p×A_eff − F_offset` 得 A_eff、F_offset，写入 .env 的 PANTO_A_EFF / PANTO_F_OFFSET。
   - 测量杆长/比例 r 校准 PANTO_L1/L2/THETA_RATIO。
   - ⚠️ **阈值联动**：真实气囊 A_eff 可能远大于 0.001，接触力 100N 对应压力可能只有几 kPa~几十 kPa。若工作压力低于低压报警阈值 100kPa 会持续报"低压报警"——此时应把 THRESHOLDS.pressLow（plc-packet.js）和 PLC 程序判阈一起调到工作压力以下；同理 F_TARGET 不要选在阈值上（模拟器默认 A_eff=0.001 时 100N↔100kPa 恰好压在低压阈值上，闭环时会有 0xC2 偶发报警，属阈值标定问题而非故障）。
5. **小步自动**：先只开力环自动，观察比例阀动作平稳、测量收敛；确认无振荡后再开姿态环。
6. **Z-N 整定**：先力环后姿态环，各一次，期间不要操作其他机构。若整定报"纯滞后占比过大"（T≤L），说明对象滞后太大，改用保守手工参数（Kp 减半、Ki 再减半起步）。
7. **异常联调**：注入真实异常（断一路传感器线→低压报警；堵比例阀→压力异常），确认平台告警与现场一致。

## 10. 附录：公式、文献与 API

### 10.1 公式与出处

1. **位置式并联 PID，微分先行**（控制量 = Kp·e + Ki·∫e·dt − Kd·dy/dt，积分条件累积抗饱和 + 输出硬钳位）
   — Åström & Hägglund, *PID Controllers: Theory, Design, and Tuning*, 2nd ed., ISA, 1995。
2. **Z-N 开环阶跃整定**：Δu 阶跃 → 拟合 FOPDT `K·e^(−Ls)/(Ts+1)`（尾部两点回归联合估计 T/L）→ `Kp=1.2T/(K·L)，Ti=2L，Td=0.5L`（Ki=Kp/Ti，Kd=Kp·Td）
   — Ziegler & Nichols, "Optimum Settings for Automatic Controllers", *Trans. ASME* 64:759-768, 1942。
3. **接触力-气囊力平衡**：`F = p_air × A_eff − F_offset`，静态接触力 70~120N（默认目标 100N）
   — EN 50367:2012 *Railway applications — Current collection systems*。
4. **两连杆正运动学**（剪式近似 θ2 = r·θ1）：`H = L1·sinθ1 + L2·sin(r·θ1)`，反解 θ1 二分法（0~88°）
   — Craig, *Introduction to Robotics: Mechanics and Control*（标准平面二连杆）。

### 10.4 关键实现注意点（实测总结）

- 压力寄存器 **×10**（0.1kPa），×100 在 1000kPa 异常时溢出 uint16。
- 平台写回**保活**：输出不变时每 5s 重写，防 PLC 看门狗/模拟器漂移干扰 Z-N 整定。
- Z-N 整定**必须从稳态开始**；整定结束后自动恢复整定前的自动/手动状态。
- 告警**去重**：同类型 10s 内且数值变化 <5% 不重复入库。
- 旧固件（状态字 bit6=0 且序号=0）自动回退平台侧缓冲均值路径，新旧固件可混用。
