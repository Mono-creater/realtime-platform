切换路径
⇄ .env 永久切换（推荐）
改 PLC_MODE / PLC_HOST / PLC_PORT / PLC_REG_* → 重启 server。模拟器闭环 → 真实 PLC 只需改两个地址。
⇄ 运行时临时切换
POST /api/plc/mode 或页面按钮，无需重启；但重启后回到 .env 原值，且不重新读取 .env。
← 自动回退（切 real 连不上时）
connectPLC 失败 → 自动退回纯模拟，且不会自动重试；修好 PLC 后需再切一次或重启。
三个必须记住的行为
① 数据库只在启动时按初始 PLC_MODE 加载：启动为 simulation 时，运行中切 real 也不会落库，要落库必须 real 启动 + DATABASE_URL。
② 寄存器段必须与 PLC 程序一致（标准型 30001 段 / Easy 型 D2001 段），否则数据全 0 或错位。
③ 切真实模式前建议先走模拟器闭环验证整条链路（采集→告警→写回→整定），再指向真机。
